# Cineteca — Plataforma de Filmes e Séries

Site para catalogar filmes e séries, dar notas, marcar o que já foi assistido e acompanhar um ranking pessoal.

## Funcionalidades
- Catálogo com busca por título/gênero e filtro por filme ou série
- Avaliação de 1 a 5 estrelas
- Ranking ordenado pelas suas notas
- Lista de títulos assistidos
- Cadastro de novos títulos
- Dados salvos no navegador (localStorage)
- Layout responsivo e tema claro/escuro automático

## Tecnologias
HTML5 · CSS3 (Grid, variáveis CSS, media queries) · JavaScript puro (DOM, eventos, localStorage)

## Como rodar
1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador

## Estrutura
- `index.html` — estrutura da página
- `style.css` — estilos
- `script.js` — lógica (filtros, avaliações, ranking, armazenamento)
